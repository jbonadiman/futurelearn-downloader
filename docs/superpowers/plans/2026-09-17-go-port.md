# Go Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Python `futurelearn-downloader` (v0.2.5) with a Go CLI that behaves identically for every flag, output path and resume rule.

**Architecture:** Flat `main.go` for the CLI, `internal/` packages split by responsibility: `course` (tree + names), `fetch` (HTTP/HLS/localisation), `markdown` (page + ToC rendering), `quiz`, and `scrape` (orchestration). No cgo, one static binary, stdlib `flag`.

**Tech Stack:** Go 1.24+, `github.com/bogdanfinn/tls-client` (Chrome impersonation, required to get past Cloudflare), `github.com/JohannesKaufmann/html-to-markdown/v2` (HTML→Markdown), `ffmpeg`/`ffprobe` via `os/exec`.

**Spec:** `docs/superpowers/specs/2026-09-17-go-port-design.md` — read it first; it carries the parity contract, the Cloudflare decision, the HLS argument vectors and the fixture rules.

## Global Constraints

- `go 1.24` in `go.mod`; `CGO_ENABLED=0`; module path `github.com/jbonadiman/futurelearn-downloader`.
- Dependencies, exactly: `github.com/bogdanfinn/tls-client` v1.16.0, `github.com/bogdanfinn/fhttp` v0.6.9, `github.com/JohannesKaufmann/html-to-markdown/v2` v2.5.2.
- No CLI framework — stdlib `flag`, 14 flags, no subcommands.
- Markdown parity is **structure-equivalent**: same headings/lists/links/images/tables/order. Whitespace and table padding may differ. Do not chase byte-identical output.
- Fixtures are synthesised (`internal/testdata/README.md`): never commit captured course content, and never edit a fixture to make a test pass.
- The only behaviour delta is bounded Cloudflare profile rotation on 403 (`Chrome_152`, `Chrome_144`, `Chrome_133`, ≤3 attempts spaced by `--delay`).
- User-facing lines (`WARNING:`, `Done. Course saved under:`, `! fetch failed:`) stay verbatim.
- Every port cites the Python source it replaces. That source lives in `src/futurelearn_downloader/` until Task 12 deletes it.

// tokens collapses markdown to the shape that must match: headings, list items,
// link and image destinations, table rows, and blockquote markers.
var tokenRE = regexp.MustCompile(`(?m)^(#{1,6} .+)$|^\s*(?:[-*+]|\d+\.)\s+(.+)$|!\[[^\]]*\]\(([^)]+)\)|\[[^\]]*\]\(([^)]+)\)|^(\|.+\|)$|^(>+)\s`)

func tokens(md string) []string {
	var out []string
	for _, m := range tokenRE.FindAllStringSubmatch(md, -1) {
		for i := 1; i < len(m); i++ {
			if m[i] != "" {
				out = append(out, strings.Join(strings.Fields(m[i]), " "))
				break
			}
		}
	}
	return out
}
